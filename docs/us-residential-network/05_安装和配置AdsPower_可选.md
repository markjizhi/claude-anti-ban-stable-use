# 第 5 件事：安装和配置 AdsPower（可选）

需要独立浏览器环境时做这一项。只用普通浏览器，可以跳过，直接做 [第 6 步](06_检查网络与日常使用.md)。

详细操作和完整验收见 [AdsPower 独立配置教程](../adspower/README.md)。完成后回到 [第 6 步](06_检查网络与日常使用.md)。

## 下载入口

[AdsPower 官方下载页](https://www.adspower.net/download)，支持 Mac 和 Windows。让 Codex 选择对应安装包；你本人注册或登录自己的 AdsPower 账户。

## 配置后的路径

**AdsPower → 自己的美国 VPS → 同一个美国静态住宅出口。**

浏览器直接连接 VPS，不依赖电脑上的 ClashFX。

## 让 Codex 做什么

1. 从官网下载并安装 AdsPower，已有应用就复用，选择已安装且可用的浏览器内核。
2. 在同一美国 VPS 建立有认证的 HTTPS 代理入口，并把入口路由到已验证的美国住宅出站。由 Codex 检查服务器后选择可用端口。
3. 配置匹配 VPS 主机的可信证书、自动续期与来源白名单；可采用 TLS 前端转发到仅监听 VPS 回环的认证 HTTP 后端。先检查端口与已有服务，不暴露未认证代理。
4. 在 AdsPower 新建一个本人环境，填写下表；关闭“使用系统代理连接代理”。确保 VPS 接入不会被电脑 TUN 再捕获。
5. 浏览器环境的时区设置为“基于 IP”，打开真实页面核对时区与已验证的住宅出口一致；自动识别有误时按已核实的时区修正。检查出口和目标网页，再测试关闭 ClashFX 时浏览器仍能通过 VPS 上网，测试后恢复原状态。
6. 记录结果，继续第 6 步。

| 填写项 | 应填写 |
|---|---|
| 代理类型 | HTTPS |
| 主机 | 自己的美国 VPS 地址，或匹配证书的域名 |
| 端口 | VPS 的 HTTPS 入口端口 |
| 代理账号、密码 | VPS 为该入口生成的专用认证 |
| 使用系统代理连接代理 | 关闭 |

主机不能填电脑回环地址；认证不能混用住宅商家的账号。[AdsPower 代理设置说明](https://help.adspower.com/docs/proxy_types)

换宽带后若连接失败，先让 Codex 检查 VPS 来源白名单和证书。付款、账号登录与系统授权由本人完成。
