# 第 2 件事：购买美国静态住宅 IP

这一份只负责买固定住宅出口。已经买好的产品直接复用。

## 购买入口

我使用的是 **IPFLY 美国静态住宅代理**，购买记录为旧金山出口。

- [IPFLY 官网](https://www.ipfly.net/zh-cn/)
- [静态住宅 / ISP 产品入口](https://www.ipfly.net/zh-cn/isp-proxies/)

选择 **静态住宅（ISP）→ 美国 → 1 个固定 IP**。有城市选项时可选旧金山；实际库存、周期与费用由 Codex 帮你核对后确认。

## 你要做什么

注册或登录自己的 IPFLY 账户。Codex 帮你确认产品和订单后，你自己付款。付款后回复：“住宅 IP 已付款，请继续。”

## 让 Codex 做什么

1. 确认产品是美国静态住宅 / ISP，而非轮换产品；核对固定性、使用周期、费用和接入协议。
2. 协助准备订单，付款前展示详情并停下，等待本人付款。
3. 开通后从本人控制台取得：代理主机、端口、账号、密码、固定出口 IP。
4. 安全保存认证资料，稍后从美国 VPS 测试它能否使用，再执行 [第 3 步](03_安装ClashFX.md)。

住宅产品与 VPS 是两笔独立购买。住宅代理主机用于连接，固定出口 IP 用于核对结果；不能把住宅账号当成 VPS 登录账号。[商家使用说明](https://doc.ipfly.net/en/Auth/Static)
