# 美国住宅网络：从这里开始

极致先生 · 原稿 2026-10-14 · 公开整理 2026-10-24

你不用学习服务器命令。把这个文件夹交给自己的 Codex，让它按步骤帮你做；你负责付款、登录和系统要求的本人授权。

最终网络：**你的电脑 → ClashFX → 你的美国 VPS → 你的美国静态住宅 IP**。

## 你只做三件事

1. 下载或克隆本仓库，用本机 Codex 打开这个文件夹。
2. 打开 [给 Codex 的启动话术](prompt.md)，把整段复制给 Codex。
3. 按 Codex 提示完成购买付款、登录或系统授权。付款后回复“已付款，请继续”。

Codex 需要能够访问本机文件和终端。有浏览器工具时，可以协助选购和填订单；没有时，它会给你购买入口和下一步动作。付款始终由你自己完成。

## 给 Codex 的执行约定

先问电脑系统、购买预算和是否需要 AdsPower，再按 01—06 推进，每次只给用户一个需要本人完成的动作。每完成一步，在仓库外私有工作目录中的 `部署进度.md` 记下结果、当前阶段和下一步，方便付款后继续。

购买时，付款前展示产品、地区、数量、周期、总价和续费方式，等待本人完成；不要代付或默认开启自动续费。登录、验证码和管理员密码在对应安全界面由本人处理。

服务器登录和代理认证资料放在独立私有位置，不写进这些分享文档或进度文件。只操作用户自己的服务器和明确授权的应用。原有系统与服务先备份，不重复重装。
