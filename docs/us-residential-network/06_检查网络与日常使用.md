# 第 6 件事：检查网络与日常使用

这一步用于确认 Codex 真的搭好了。

## 让 Codex 检查

1. 普通电脑请求显示自己购买的美国住宅 IP。
2. Claude Code / 桌面端等所需应用的实际请求进入同一美国线路。用户完成登录后，允许测试时再验证一次真实响应。
3. 若配置了备用协议，逐个测试，确认最终出口相同。
4. 若装了 AdsPower，在真实浏览器核对出口，并确认它直接连接美国 VPS、可以独立于 ClashFX 使用。
5. 服务和客户端重启后仍可用，局域网与原有远程连接正常。
6. 公网 IPv6、DNS 和断线行为分别检查；未配置或未通过的保护明确记录，不当成已完成。
7. 读取电脑实际生效的系统时区，确认与美国住宅出口对应的时区一致；重新打开应用后复核。若装了 AdsPower，也核对真实浏览器页面的时区。原时区、目标时区、验证结果和恢复方法记入部署进度。

在仓库外私有工作目录的 `部署进度.md` 写清已完成项与待处理项，再给用户一份简短的本人使用说明。不要用作者的测试记录代替这台电脑的实测。

## 你以后怎么用

- **普通浏览器或 Claude Code：** 启动电脑代理客户端，使用“美国住宅出口”，保持已验证的代理与增强模式设置。
- **AdsPower：** 打开已配置的美国环境；它直接连接美国 VPS。
- **遇到问题：** 把错误提示发给原 Codex 对话，让它先读 `部署进度.md`，再从出错的步骤继续，不重复购买或重装。

住宅产品与 VPS 都要在到期前按本人需要续费。网络出口固定不代表平台账号一定获准使用，也不保证模型响应速度。
