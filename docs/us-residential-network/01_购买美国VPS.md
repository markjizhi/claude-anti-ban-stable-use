# 第 1 件事：购买美国 VPS

这一份只负责买服务器。已经有美国 VPS，直接让 Codex 检查并复用。

## 购买入口

我使用的美国 VPS 平台是 **搬瓦工 BandwagonHost**。

- [官网](https://bandwagonhost.com/)
- [VPS 套餐入口](https://bandwagonhost.com/vps-hosting.php)

选择美国机房，系统建议 Ubuntu 24.04。这里的服务器用于网络中转，不是在上面运行 AI 大模型。让 Codex 按你的预算、当前套餐和线路选择合适配置。

## 你要做什么

注册或登录自己的搬瓦工账户。Codex 准备好订单后，你核对地区、周期、价格和续费方式，再自己付款。付款后回复：“VPS 已付款，请继续检查开通。”

## 让 Codex 做什么

1. 查看当前美国套餐，按本人预算推荐一个并说明费用。
2. 有浏览器工具时协助填写订单，到付款前停下；无法操作网页时给出手动购买入口。
3. 本人确认付款后，检查服务器是否开通，取得公网地址、SSH 端口、登录用户和管理权限。
4. 登录服务器并确认系统可用，把密码或密钥安全保存在本人私有位置。
5. 记录此步完成，再执行 [第 2 步](02_购买美国静态住宅IP.md)。

平台网站登录密码与服务器 SSH 登录资料是两套信息。已有服务器不重装；缺哪个必要参数，只问哪个。
