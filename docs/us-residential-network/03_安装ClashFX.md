# 第 3 件事：安装 ClashFX

这一份只负责安装电脑代理客户端。已经安装的，检查版本和运行情况即可。

## 下载入口

**Mac：**[ClashFX 官方下载页](https://github.com/Clash-FX/ClashFX/releases/latest)。由 Codex 确认当前正式版，下载对应安装包。

ClashFX 是 macOS 客户端。**Windows：**让 Codex 从 [Clash Verge Rev 官方下载页](https://github.com/clash-verge-rev/clash-verge-rev/releases/latest) 安装对应版本，沿用同一美国网络方案。

## 你要做什么

允许 Codex 协助下载安装。若系统要求批准安装、网络助手或管理员验证，在自己的电脑上完成。暂时不用找订阅或购买节点。

## 让 Codex 做什么

1. 检查电脑系统与已有客户端，已装可用版本就复用。
2. 从上述官方来源下载安装；保留用户已有网络配置。
3. 确认应用能打开、必要网络权限可用。
4. 把“客户端已安装”记录到进度，再执行 [第 4 步](04_搭建美国网络.md)。

真正的美国节点会在下一步生成和导入，安装完成不等于网络已经搭好。
